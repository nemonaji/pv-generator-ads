# 중복 이미지 정리 (Duplicate Image Finder)

기기에 저장된 이미지 중 같은 이미지를 찾아 그룹으로 보여 주고, 선택한 이미지를 삭제하는 안드로이드 앱입니다.

설치 파일: [`dist/duplicate-image-finder.apk`](dist/duplicate-image-finder.apk) (Android 8.0 이상)

## 같은 이미지로 보는 조건

설정의 체크박스로 각각 켜고 끌 수 있습니다. 설정을 바꾸면 다시 검사하지 않고 결과가 바로 갱신됩니다.

| 조건 | 설명 |
| --- | --- |
| 완전히 같은 파일 | 파일 내용이 완전히 동일한 복사본 |
| 해상도·화질만 다른 이미지 | 크기를 줄였거나 다시 압축한 이미지 |
| 텍스트 등이 추가된 이미지 | 글자·스티커·워터마크처럼 일부만 바뀐 이미지 |
| 일부를 잘라낸 이미지 | 원본의 일부분만 남긴 이미지 (크기를 바꿨어도 인식) |

각 그룹에서 가장 큰 이미지가 "원본 (유지)"로 표시되고 나머지가 삭제 대상으로 자동 선택됩니다.
사진을 누르면 선택/해제, 길게 누르면 크게 볼 수 있습니다.

## 동작 방식

1. 이미지마다 64px 흑백 축소본과 색상 히스토그램으로 지문을 만듭니다 (`core/Fp.java`). 지문은 캐시되어 다음 검사는 빠릅니다.
2. 파일 크기가 같은 파일은 MD5로 완전 동일 여부를 확인합니다.
3. 모든 쌍을 비교합니다 (`core/Matcher.java`).
   - 비율이 같으면 전체를 블록 단위로 비교: 차이가 없으면 해상도/화질 차이, 일부 블록만 다르면 텍스트·수정.
   - 그 외에는 한 이미지가 다른 이미지의 일부인지 위치·배율을 탐색(잘림).
4. 원본을 기준으로 그룹을 만들고 설정에 맞는 것만 표시합니다 (`core/Grouper.java`).

## 빌드

```bash
gradle assembleRelease
```

Android SDK(platform 35, build-tools)와 JDK 17 이상이 필요합니다. 서명 키(`keystore/app.keystore`)는 재설치가 가능하도록 저장소에 포함한 테스트용 키입니다.
